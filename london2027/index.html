Everything you enter is saved in this browser first. This page contains no personal content of its own: your lists and settings live in a data file you import once. To keep several devices in step, connect a private GitHub repository below. Without it, each browser keeps its own copy, and clearing site data erases it, so export a backup now and then.

Sync between devices

Optional. Keeps a copy of everything in a file in a private GitHub repository, so every device you connect stays up to date. You need a private repo and a fine-grained personal access token limited to that one repo, with Contents set to Read and write. The token is kept in this browser only. Never put it, or the data file, in the public repo.
